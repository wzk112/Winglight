# Winglight 1.5.2

本次发布同步演示视频使用的 macOS 功能，并修复发动机、模型切换和界面交互问题。

## 更新内容

- 校正 737 两侧发动机风扇轴心，补齐风扇后方的内部遮挡，修复从进气道看穿背景的问题。
- 保留各机型风扇原始 UV 和整流锥贴图，平滑 A320 进气口材质边界；厦航文字采样修正仅作用于对应 787-9 模型。
- 优化旋转、缩放与时间滑块输入，避免频繁重设 Metal 绘制模式及刷新整个侧栏。
- 缓存当前和最近使用的模型、遮挡结构与气流数据，限制内存占用；切换时避免旧涂装显示在新模型上。
- 面板一次只显示一个，打开时禁用后方控件；玻璃滑块支持明确的键盘焦点，时间步进为一分钟。
- 发布包含全部 504 项资源的新资源包，已经内置修正后的模型，普通源码构建无需重新转换资产。
- 收录使用应用 Metal 渲染器的离线演示导出工具及原生窗口录制工具。

本版保留 9 种机型、17 套模型装配、309 个机型／涂装组合，以及可旋转视角、
日照和时间滑块、四种背景、五种天气、气流可视化、外部灯光、夜间客舱照明、
HDR/EDR、场景过渡与 Liquid Glass 界面。
视频的字幕、章节进度条、配乐和片尾图形属于视频剪辑内容。

此前的全目录检查覆盖 309 个组合的双侧发动机及 17 套装配的多角度视图；
具体过程和已知素材限制见 docs/ENGINE_UI_AUDIT.md。本次发布另行完成源码、
资源校验、构建、签名和下载后验证，结果记录在 docs/releases/1.5.2-validation.md。

## 下载与安装

- Winglight-1.5.2-macOS-arm64.zip：完整应用，版本 1.5.2 / build 12。
  需要 macOS 15+ 和 Apple Silicon。解压后将 Winglight.app 拖到「应用程序」。
  全部运行资源已内置，无需另下资源包。
- macOS 26+ 使用原生 Liquid Glass，较早版本使用系统材质回退。
- 应用采用 Apple Development 签名，尚未做 Developer ID 公证。macOS 可能
  要求在「系统设置 → 隐私与安全性」中允许打开，也可自行从源码构建。
- SHA256SUMS.txt 提供下载文件校验值；SOURCE.txt 记录对应版本和提交。
