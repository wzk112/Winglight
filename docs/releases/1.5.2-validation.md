## Correspondence with the demonstration

- All 501 runtime binary resources match the application used to render the video.
- The Metal shader and livery catalog match the video application.
- Nine fixed 4720 × 3280 RGBA16F captures are byte-identical to the video renderer:
  clouds by day/night, airflow, studio, night storm, stars, wireframe, 777 airflow
  in rain, and the 2× MSAA mode. HDR audit headroom was fixed at 6 for comparison.
- Returning to a cached model exposed a race in the diagnostic harness: it could
  check readiness before asynchronous loading state was published. The audit now
  waits for that publication; the nine-scene release run passes. This changes the
  diagnostic harness, not normal rendering or the light flash timing.
- These captures establish renderer correspondence, not physical display luminance
  or sustained frame rate on every supported Mac. Video chapter cards, subtitles,
  music and end graphics are editorial elements rather than application controls.

## Distribution checks

The locally built bundle passes strict deep code-signature verification and includes
the license inventory. Apple Development signing is used; this release is not
Developer ID notarized. The release's SHA256SUMS.txt and SOURCE.txt identify the
application archive, source commit and resource pack. Public-download verification
is recorded in a subsequent update to this file on the main branch.

Detailed prior engine/catalog/interaction coverage and remaining source limitations
are in docs/ENGINE_UI_AUDIT.md. The locationUnknown limitation remains disclosed.
