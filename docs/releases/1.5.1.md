# Winglight 1.5.1

本次更新包含保持画质的性能优化，以及更自然的闪电通道和回击效果。

## 更新内容

- 减少对画面没有贡献的光照、阴影和背景计算，结束场景过渡后停止读取旧画面。
- 保留原有分辨率、MSAA、模型和贴图、粒子数量、阴影配置与 HDR 上限。
  在开发机 M5 Pro、4720 × 3280、4× MSAA 的六个代表场景中，GPU 时间降低
  **4.0–10.4%**。这是受控 GPU 计时结果，不代表所有设备的帧率或续航增幅。
- 闪电改用细而有折角的主通道、不规则分支、云层局部照明，以及沿同一通道
  连续发生的短促回击；飞机反光使用现有材质响应。保留减少动态效果及 SDR/HDR 限制。
- 普通窗口减少诊断数据构造和不必要的纹理读取；修正隐藏窗口暂停后的计时记录。
- 增加可复现的全分辨率 GPU 计时与浮点画面对比工具。

40 项 Swift 测试通过；八个保持原视觉的场景完成逐通道浮点对比，最大差异
不超过 0.00048828125，HDR 峰值与超出 SDR 的通道数量相同。
闪电作为有意的视觉更新单独检查。完整条件及边界见
[性能记录](https://github.com/wzk112/Winglight/blob/v1.5.1/docs/PERFORMANCE.md)。

## 下载与安装

- **完整应用：`Winglight-1.5.1-macOS-arm64.zip`**。需要 macOS 15+ 和
  Apple Silicon，版本 1.5.1 / build 10。解压后将 `Winglight.app` 拖到「应用程序」。
  内置全部运行资源，无需另外下载资源包。
- 应用使用 **Apple Development 签名，未做 Developer ID 公证**。macOS 可能
  要求在「系统设置 → 隐私与安全性」确认允许打开；也可从源码构建。
- `SHA256SUMS.txt` 提供应用 ZIP 及下述共享资源包的 SHA-256。应用包旁的
  `SOURCE.txt` 记录对应的 Git 提交、源码及资源包地址。
