# 发动机与交互检查 · 2026-10-25

本地 1.5.2（build 11），尚未发布。基线为已发布的 1.5.1。

已安装到 `/Applications/Winglight.app`，安装后签名校验通过，执行文件、Metal
库和最终 737 网格／遮挡文件与构建产物的 SHA-256 一致。原 1.5.1 保存在本次

## 修正

- 737 右侧风扇中心原先偏离动画轴约 0.25 m。导入较新发动机组件时，
  原代码仅按进气唇边对齐，并假定左右横向坐标相同；现在按实际圆形风扇轴
  整体平移各侧组件。渲染网格和遮挡 BVH 同步重建，未缩放风扇来遮掩偏心。
  另外补入进气道内部的深色压气机遮挡面，阻止叶片缝隙透出后方天空或机身。
  这是内部结构的视觉近似，不是压气机叶级模型。
- 原导入器覆盖全部风扇 UV 并清除纹理编号，导致 A330、777 等的原生叶片和
  旋锥纹理丢失。现在保留源 UV，单独计算没有源贴图时使用的程序化旋锥坐标。
- A320 深色短舱的金属进气口边界原来按整块三角面分类，出现锯齿；改为连续
  的机身坐标材质分界。厦航投影模型的文字局部修正不再影响其他机型的同号图集。
- 连续输入不再反复设置 `MTKView.isPaused`、按需绘制模式及刷新率；旋转、
  缩放只通知 Metal 视图。原来每次拖动都会广播整个 SwiftUI 界面的变化。
- 当前及最近一套模型、遮挡结构和气流保留在有上限的缓存中（最多两套、
  合计目标 384 MiB；单个活动模型始终保留）。载入结束前不会将缓存模型与旧贴图混用。
- 设置、说明、机型库、涂装库改用同一活动面板状态，避免关闭后出现藏在下面的
  面板。弹窗显示时，背景控件也从辅助功能访问中隐藏。
- 液态玻璃滑块点击后取得键盘焦点；时间方向键每次一分钟，其他滑块每次量程
  的 1%。焦点提示放在滑块手柄上，避免整条控件出现大矩形描边。

## 流畅度

同一台 Apple M5 Pro，A320 云层场景，原生窗口持续以 60 Hz 扫过一天的太阳时间。
两次各 600 帧，内部 4720×3280、4× MSAA、相同高精度设置。
没有降低模型、纹理、气流密度或 HDR 上限。

| 指标 | 1.5.1 | 本地修复版 |
| --- | ---: | ---: |
| 平均帧间隔 | 20.20 ms | 16.92 ms |
| 帧间隔 P95 | 28.19 ms | 18.28 ms |
| 主线程渲染提交平均耗时（含等待 drawable） | 6.77 ms | 0.27 ms |
| GPU 平均耗时 | 6.96 ms | 7.28 ms |

改善主要来自提交节奏和界面刷新，GPU 耗时未降低。新增风扇纹理采样仍保持
相同画质设置下的交互接近 60 帧。这是一次开发机对比，不是所有 Mac 或全部
天气场景的性能保证。原始数值见 `interaction-performance-2026-10-25.json`。

## 仍存在的源素材限制

检查通过不表示工程级模型或逐架注册号的真实发动机配置。A320 仍使用 CFM
几何；部分 IAE／neo 涂装没有兼容的 CFM 短舱贴图，继续使用素色回退，不能
视为精确发动机涂装。厦航 787 仍为已注明的 2K 侧投影适配。A330 进气口轮廓、
部分接缝和发动机内部细节仍受上游几何约束；本轮没有凭空生成航空公司标志或
将低分辨率纹理放大后宣称新增细节。未验证任意观察位置下所有零件绝无穿模。
